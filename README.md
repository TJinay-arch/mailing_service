# Mailing Service

Веб-приложение для управления email-рассылками.
Позволяет создавать сообщения, управлять получателями и запускать автоматические рассылки.

## Возможности

* регистрация и авторизация пользователей
* создание и редактирование сообщений
* управление получателями рассылок
* создание и запуск рассылок
* просмотр статистики отправки
* логирование попыток отправки
* разграничение прав пользователей (пользователь / менеджер)

## Технологии

* Python 3
* Django
* PostgreSQL / SQLite
* Redis (кеширование)
* Bootstrap 5
* Celery (фоновые задачи)

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/your_username/mailing_service.git
cd mailing_service
```

Создать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Применить миграции:

```bash
python manage.py migrate
```

Создать администратора:

```bash
python manage.py createsuperuser
```

Запустить сервер:

```bash
python manage.py runserver
```

## Кеширование

В проекте используется Redis для кеширования:

* статистики dashboard
* списков получателей
* списков рассылок

Настройка в `settings.py`:

```python
CACHE_ENABLED = True

CACHES = {
    "default": {
        "BACKEND": "django.core.cache.backends.redis.RedisCache",
        "LOCATION": "redis://127.0.0.1:6379/1",
    }
}
```

## Роли пользователей

**Пользователь**

* управляет своими получателями
* создает рассылки
* просматривает статистику

**Менеджер**

* видит всех пользователей
* управляет рассылками
* имеет доступ к панели управления

## Структура проекта

```
mailing_service/
│
├── clients/        # получатели рассылок
├── mailings/       # рассылки и сообщения
├── users/          # пользователи и авторизация
├── dashboard/      # главная страница и статистика
└── config/         # настройки проекта
```

## Интерфейс

Интерфейс построен на **Bootstrap 5** и включает:

* панель управления
* списки рассылок
* управление получателями
* статистику отправки сообщений
